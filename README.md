# 📰 Fake News Keyword Analyzer

A simple web-based application that analyzes news text and identifies important keywords using Python and Flask.

live website https://fake-news-keyword-analyzer.onrender.com/

## 🚀 Features

- 📝 Enter news text
- 🔍 Extract important keywords
- 📊 Analyze text content
- ⚡ Fast and simple interface
- 🌐 Web-based Flask application
- 📱 Responsive design

## 🛠️ Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
- NLP / Text Analysis

## ▶️ Run Locally

Install the dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```

## 🌐 Deployment

The application can be deployed using Render.

**Build Command:**

```bash
pip install -r requirements.txt
```

**Start Command:**

```bash
gunicorn app:app
```

## 🎯 Objective

The objective of this project is to demonstrate basic NLP-based keyword analysis of news content through a simple web application.
